## 1. コンセプト

> **「世界は、いま鳴り響いている一つの大きな音楽です。」**

「Lyra」はギリシャ神話で詩人オルフェウスが奏でた竪琴、そしてこと座の名前。
**夜空に浮かぶ星座が、ブランドの原点であり、この地図の隠れた主役**です。

子供たちが地図を覗き込むたびに、

- 大陸 = オーケストラの各セクション（弦・管・打・声）
- 国 = 一つひとつの音符
- 緯線・経線 = やわらかな五線譜
- 海 = 旋律が流れる空間
- そして地図の右上、夜空の縁に小さく**こと座（Lyra）**が輝く

──そんな「世界全体が美しい音楽になっている」物語として、地図を再発明します。

### なぜこのコンセプトが最適か

| ご要望                             | 本提案がどう応えるか                                  |
| ---------------------------------- | ----------------------------------------------------- |
| ビジョン「美しい旋律で心を豊かに」 | コンセプト自体が"地図 = 旋律"                         |
| ポジティブで平和な表現             | 国境線をやめ、音符・楽器・動物で繋ぐ                  |
| ノンバーバルな理解                 | 文字よりも絵・色・音楽記号で語る                      |
| 何度見ても新しい発見               | "隠し音符 88 個（ピアノの鍵盤数）" を散りばめる仕掛け |
| インテリアとしての美しさ           | 大人が額装したくなる "Editorial × 北欧テイスト"       |

## 2. ビジュアル設計

### 2-1. 全体トーン

- **手描きの温かみ × エディトリアルの洗練**
- 水彩テクスチャ + フラットイラストのハイブリッド
- 線は細く、角は丸く。"優しさ"を画面の隅々まで通す

### 2-2. 配色（ご指定カラーを音楽記号として運用）

```
ターコイズブルー  #40E0D0  → 海・空・主旋律（メロディ）
コーラルオレンジ  #FF7F50  → 大陸・人の暮らし・アクセント
アイボリーホワイト #FFFFF0  → ベース（楽譜の余白）
サンフラワー      #FFD700  → 星・楽器・"発見"のハイライト
```

補色として深い藍（#1F3A5F）を 5% だけ使い、画面を引き締めます。

### 2-3. 大陸別「楽器セクション」割り当て

| 大陸         | オーケストラの役   | 象徴イラスト例                                 |
| ------------ | ------------------ | ---------------------------------------------- |
| ヨーロッパ   | 弦楽器セクション   | バイオリン・ピアノ・エッフェル塔・白鳥・大聖堂 |
| アフリカ     | 打楽器セクション   | ジャンベ・サバンナの動物たち・キリマンジャロ   |
| アジア       | 木管楽器セクション | 尺八・琵琶・パンダ・桜・象・タージマハル       |
| アメリカ大陸 | 金管楽器セクション | トランペット・ジャズ・アンデス・トーテムポール |
| オセアニア   | 声楽（聖歌隊）     | ディジュリドゥ・コアラ・サンゴ礁・キーウィ     |
| 南極         | 休符（しん…）      | ペンギン・オーロラ・"世界の余白"               |

→ 各国に **必ず 1 つ以上の「文化アイコン × 動物 × 楽器」のトリオ**を配置。

### 2-4. ノンバーバル設計の工夫

- **国名は最小限の英字 + ふりがな付き日本語**（保護者と子供が一緒に読める）
- 国の場所は色面で示し、**文字が読めなくても "絵で旅できる"**
- 動物・楽器・建造物はピクトグラム的なラインで統一 → 直感で意味が伝わる
- 国旗は**使わない**（政治的・宗教的中立性を保つ Lyra Design の世界観）

### 2-5. "夢中になれる" 仕掛け（リピート鑑賞性）

1. **隠し音符 88 個**（ピアノ鍵盤数）── 見つけると小さな喜び
2. **動物の親子ペア**を 12 箇所に配置（家族の温かさ）
3. **「世界の挨拶」吹き出し**を各大陸に 1 つずつ（ノンバーバルだが知的好奇心を刺激）
4. **裏面プレゼント**：A2 裏面に「楽器辞典 × 動物辞典」のミニカード（追加コストなし／印刷会社の両面対応で実現）

## 6. なぜ私にお任せいただきたいか

1. **コンセプトが"商品名"と"ブランド名"両方に直結している**
   Lyra（こと座）を地図の中に隠す物語 = 二度と真似できない独自性
2. **国境線を描かない決断**
   政治的にニュートラル → 海外輸出・贈答用にも安心して使える
3. **大人もインテリアとして買いたくなる完成度**
   ターゲット 3 層（子・親・大人）全員に響く設計
4. **裏面辞典という"二度目の体験"を無償提案**
   Lyra Design 第一弾商品の "話題性" を最大化
