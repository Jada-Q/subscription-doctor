# Lyra Design「希望のシンフォニー世界地図」提案一式

依頼番号 **5529362**（Misato Tanaka 様）への最終提出パッケージ。

## 同梱ファイル

| ファイル            | 用途                                                                |
| ------------------- | ------------------------------------------------------------------- |
| `PITCH_SHORT.md`    | **コンペコメント欄に貼り付け用**（約 800 字、これが最初に見られる） |
| `PROPOSAL.md`       | フル提案書（コンセプト・仕様・スケジュール・契約）                  |
| `DESIGN_BRIEF.md`   | 受注後の制作仕様書（カラー・タイポ・レイヤー・チェックリスト）      |
| `layout-mockup.svg` | A2 レイアウト構成図（ブラウザで開けば即プレビュー可）               |

## 提出フロー（推奨）

1. **`PITCH_SHORT.md` の本文をコメント欄にペースト**
2. ペースト直前に「より詳しい提案書とラフ案を別途お送りできます」と一言添える
3. `layout-mockup.svg` を PNG 書き出しし、添付画像として 1〜2 枚アップ
4. 選定後の本契約時に `PROPOSAL.md` + `DESIGN_BRIEF.md` を送付

## 提案の核（一行で）

**「Lyra（こと座）= オルフェウスの竪琴」というブランド名の原典を地図の中に隠し、
世界全体を一つのオーケストラとして描く。**

- 大陸 = 楽器セクション / 国 = 音符 / 緯線経線 = 五線譜
- 国境線も国旗も使わない（政治的中立・贈答適性）
- ピアノ鍵盤数 88 にちなんだ「隠し音符 88 個」でリピート鑑賞性を確保
- A2 メイン + A3 副 + 裏面ミニ辞典を無償同梱
