## 推荐动手顺序

1. **06 合同 X 光机** — 冷启动成本最低：OCR + 规则匹配管线可直接从本仓库复用。
2. **02 万物频谱仪** / **03 数学可触摸** — 零硬件成本的纯前端项目，周末可出原型。
3. **01 NILM** / **09 微气候网络** — 需采购硬件，但预算都在百元级，工程趣味最高。
4. **05 / 07 / 10** — 中期项目，各自有清晰的 4 阶段路线。
5. **04 / 08** — 社区驱动型，技术之外更依赖冷启动运营，适合作为长线种子。
