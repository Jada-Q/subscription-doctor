Analyze user feedback for kill criteria evaluation.

Input: I'll paste user comments or feedback.

Process:
1. Classify each comment: interested / skeptical / irrelevant / bug-report
2. Count conversion signals (asked for URL, asked how to use, shared own pain point)
3. Count rejection signals (said not needed, already have alternative, privacy concern)
4. Apply kill criteria: if rejection > 60% of non-irrelevant comments → KILL
5. Output: PROCEED / KILL / INCONCLUSIVE with evidence summary
